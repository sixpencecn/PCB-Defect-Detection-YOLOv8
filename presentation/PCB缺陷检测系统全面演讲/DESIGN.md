# PCB 电路板缺陷检测系统 · 全面演讲 PPT 设计方案

## 全局视觉约定

### ① 画布与安全区
- 画布 1280×720，16:9。
- 内容页：深蓝顶条 72px（y 0–72），主内容区 y 72–642，页脚 y 642–720。
- 左右安全边距 60px，内容宽 1160px；主内容内边距 24px 60px 12px，实际内容高约 534px。
- 封面 / 章节页 / 结束页全出血，省略页眉页脚。

### ② 配色方案
- 主色：宝蓝 `#1E4FA8`（顶条、编号、强调）
- 辅色：浅蓝 `#E8EFF8` / `#F0F5FC`（卡底）、中蓝 `#3D7BD9`（图表第二系列）
- 强调色：警示红 `#D9534F`、数据黄 `#FFC107`（单页合计 ≤5%）
- 底色：`#FFFFFF` / `#F7F9FC`
- 正文色：`#1A2230` / `#4A5568` / `#8B97A8`
- 线框：`#D6DCE5`

### ③ 字体系统
- 中文：思源黑 / Microsoft YaHei；英文：Arial。
- 封面中文主标 60px，英文长题 26px；章节大字 140px；页面主标 30px；卡内标题 24px；正文 20–22px；巨型数字 72px；注释 14px。

### ④ 视觉母题
- 内容页统一「深蓝顶条 + 标题 + 右侧 YOLOv8·DeepPCB 标记」，页脚左下固定「PCB Defect Detection · YOLOv8」，右下页码。
